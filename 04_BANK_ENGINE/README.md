# 04_BANK_ENGINE

Bank Engine će služiti za uvoz, prepoznavanje i automatsko knjiženje bankovnih izvoda.

## Buduće odgovornosti

- uvoz PDF izvoda
- uvoz HTML izvoda
- prepoznavanje uplata/isplata
- povezivanje po žiro računu
- pravila knjiženja
- preview prije knjiženja
- učenje sistema na osnovu prethodnih odluka
