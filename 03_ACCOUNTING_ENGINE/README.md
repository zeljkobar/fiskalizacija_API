# 03_ACCOUNTING_ENGINE

Accounting Engine će povezati fiskalne račune sa knjigovodstvom.

## Buduće odgovornosti

- KIF
- KUF
- PDV prijava
- knjiženje računa
- knjiženje storna
- knjiženje avansa
- zatvaranje kupaca
- otvorene stavke
- kartice partnera

Prva verzija ovog modula se ne razvija prije stabilnog Fiscal Engine-a.
