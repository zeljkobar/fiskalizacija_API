# 07_AI_ENGINE

AI Engine će služiti kao pomoćni sloj za automatizaciju knjigovodstvenih procesa.

## Buduće odgovornosti

- predlog knjiženja
- prepoznavanje grešaka
- objašnjenje poreskih pravila
- pomoć pri obradi izvoda
- pomoć pri klasifikaciji dokumenata
- asistencija knjigovođi

AI nikad ne smije automatski zaključiti kritičnu poslovnu operaciju bez pregleda korisnika.
